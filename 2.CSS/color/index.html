How to use css in html

CSS (Cascading Style Sheets) is used in HTML to style web pages by controlling the layout, colors, fonts, and overall design.

It can be applied in three ways: inline (inside an elements style attribute), internal (inside a < style > tag in the < head > section), and external (in a separate .css file linked with the <link > tag). Using CSS makes web pages more attractive, organized, and easier to maintain.
